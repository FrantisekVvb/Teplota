# Teplota

Interaktivní simulace ohřevu vody v hrníčku. Pod hrníčkem je hořák (stejný jako v projektu měrné tepelné kapacity), který lze zapnout a vypnout.

**Teplota** stoupá lineárně z 1 °C na 99 °C, když hořák běží. **Rychlost částic** ve vodě odpovídá teplotě — při 20 °C je to základní rychlost animace.

## Spuštění lokálně

```bash
npm start
```

Aplikace poběží na adrese **http://localhost:3473**.

## Ovládání

- **Zapnout / Vypnout hořák** — spustí nebo zastaví lineární ohřev vody
- Teploměr nad hrníčkem ukazuje aktuální teplotu
- Částice v detailu kruhu se pohybují rychleji s rostoucí teplotou
